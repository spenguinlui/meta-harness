meta-harness 是一位住在 Claude Code 裡的「AI agent 系統設計顧問」。腦中內建 13 大設計軸的 pattern library， 陪你把任何 AI agent 工具設計好、蓋出來。
harness engineering > prompt engineering · 改字 vs 改整套系統

六個入口卡片，涵蓋從第一次開 session 到 12 設計軸深度。卡住了用上面的搜尋框過濾。

入門 / Getting Started
  • 這個專案是什麼？為什麼是顧問而非腳手架？
  • 前置條件：Claude Code CLI、想設計的 target repo
  • 三行裝起來：git clone → cd → claude
  • 第一次開 session 先 /model 切最強 model
  • 不需要 .env、不需要 API key
5 主題 → 新手入口
顧問四模式 / 4 Modes
  • /design <target> — 新建或重設一個 harness
  • /healthcheck <target> — 用 13 軸定點體檢
  • /retro <target> — 飛輪 retrospective
  • /document <target> — 產雙語交付說明書
  • 不打 command 直接講白話也可（自動載入 consultant skill）
4 模式 前門
13 大設計軸 / Pattern Library
  • Tool · Context · Memory · Planning · Execution
  • Safety · Hooks · Evaluation · Observability
  • Multi-agent · Triggers · Human Interface
  • Self-verify Coverage（軸 13）
  • 每軸都是「設計參數」而非開關，彼此耦合
13 軸 → 索引
設計流程 6 步 / Design Flow
  • Step 1 需求訪談（10–20 分鐘，5 件事）
  • Step 2 建築師獨自出設計圖
  • Step 3 你 review、白話收斂
  • Step 4 分期實作落地（Stage 1/2/3）
  • Step 4.5 自驗 loop（headless 跑 ≥3 次 + 機評）
  • Step 5 驗收 · Step 6 飛輪 retrospective
6 步 + 自驗 → 決策邏輯
R-1 ~ R-12 衛生規則 / Universal Rules
  • R-1 cwd 守衛 · R-3 行數檢查 · R-5 提問自查
  • R-6 不用未解釋專有名詞 / 縮寫
  • R-8 跨層越權禁止 · R-9 framework vs 任務分流
  • R-10 可機驗 outcome 必先自驗
  • R-11 可被他人使用必交付雙語說明書
  • R-12 grep 自檢 blocking gate
12 條 + hook 強制 → 詳解
角色 & 檔案產出 / Roles & Artifacts
  • Builder vs Human：設計者 vs 每天用 target 的人
  • sessions/ 訪談紀要
  • prescriptions/ 顧問設計圖
  • experiments/<target>/runs/ 自驗證據
  • BACKLOG.md 未消化的方法學缺口
  • 真實內容全 gitignored，fork 拿到不互相污染
