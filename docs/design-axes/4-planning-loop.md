# 設計面向 4：規劃

動手之前先想：怎麼拆、先做哪個、哪裡有風險。它跟執行、評估是一組的。

## 有哪幾種形態

**一次規劃到底。** 任務開始時產一次計畫，後面純執行。簡單，但很脆弱，遇到意外就崩。

**規劃、執行、再規劃。** 執行中遇到偏差就回頭重新規劃。Claude Code 的 Plan agent 和 ExitPlanMode 屬於這種。最常用。

**分層規劃。** 先做高層的里程碑計畫，每個里程碑再展開成低層的步驟。適合複雜的遷移和長時間的任務。

**同時準備多個候選。** 產生好幾個候選計畫，評估之後選一個。成本高，但對高風險的決策值得。例如架構選型、不可逆的遷移。

**邊想邊做。** 不刻意分規劃和執行，每一步之前想一下。最自由，但複雜任務容易迷路。

## 要決定的事

### 一、什麼時候強制要有計畫

步數超過某個數字、做有破壞性的操作之前、對方的指令很模糊、評估失敗之後要重新規劃。

純查詢不必規劃，動正式環境一定要規劃。

### 二、計畫要包含什麼

至少要有：步驟清單、步驟之間的相依關係、每一步預期的輸出、風險和可以退回的點、哪些可以並行、以及檢查點（要停下來確認的地方）。

格式不結構化的話，計畫就等於聊天，沒辦法 review、沒辦法重播。

### 三、要不要審核

從鬆到嚴：自動執行（信任模型）、先空跑預覽、要人確認才執行、部分自動加上關鍵步驟手動。

風險越高，確認要越嚴。

### 四、什麼時候重新規劃

工具連續失敗 N 次、每步驗證失敗、發現當初的假設是錯的、對方補了新資訊、步數超出預算。

每個觸發點都要想清楚：是立刻停下，還是繼續嘗試？

### 五、計畫存成記憶，成果累積成 skill

這是雙向的循環。

**計畫這一端**，做完的計畫應該變成可以重用的東西：存成範本，下次遇到類似任務先召回，跟記憶系統打通（對應設計面向 3 的事件記憶）。

**成果這一端**，這是從 ai-infra-management 第一版學到的延伸。計畫跑完、實作完之後，成果本身也該被累積下來。如果同一類動作會反覆出現——例如對方拿到建議之後手寫臨時的 bash 腳本，做了兩次以上——下次就該把它抽象成 skill 或子指令，不要當成一次性的東西。

實際的例子：對方跑完 `/advise sf-project compute` 之後，手動做了一輪 EC2 監控基準。後來發現這類動作會反覆出現，就抽象成 `skills/monitoring/create.sh`。

設計時的準則：

- **什麼時候觸發**：同一個手動成果反覆出現兩次以上，或者對方明講「下次也想這樣做」。
- **抽象成什麼**：skill、子指令、或 hook。看未來要不要串接來決定。
- **跟計畫那端是對稱的**：計畫是「下次怎麼想」，skill 是「下次怎麼做」。兩者都該回灌記憶系統，不是用過就丟。
- **這是設計者的責任**：使用者通常不會、也不該去做抽象。這是設計者這一端的循環。

### 六、分層要分幾層

太淺的話，計畫等於一張待辦清單。太深的話，規劃比執行還久。通常兩到三層就夠。

### 七、哪些可以並行

計畫要標出哪些步驟可以並行。

沒標的話全部照順序跑，慢。亂並行的話會衝突，而且很難除錯。應該明確標出相依關係。

## 跟其他面向的牽連

| 面向 | 牽連在哪 |
|---|---|
| 成效評估 | 計畫該先寫好驗收條件，那個條件就是每步驗證的依據 |
| 記憶 | 做計畫時要召回過去類似任務的紀錄 |
| 執行迴圈 | 計畫的步數就是迴圈的步數預算 |
| 工具執行 | 工具的副作用宣告決定了計畫要多嚴格 |
| 權限與安全 | 有破壞性的步驟，在規劃階段就要標出確認點 |

## 常見的錯誤做法

**不做計畫直接動手。** 「我來看看」式的探索。小任務可以，複雜任務一定迷路。觸發條件要寫明確。

**做了計畫卻不照著跑。** 寫了五步，實際做的時候自由發揮，計畫變成裝飾。執行要對著計畫跑，偏離了就重新規劃。

**計畫寫太細。** 每一個工具呼叫都寫進計畫，跟實際執行差不多長。計畫是骨架，不是劇本。

**計畫寫太抽象。** 「先了解狀況、再做改動、最後驗證」，沒有任何可執行的細節。計畫至少要細到「跑哪個工具、改哪個檔案」的程度。

**沒有可以退回的點。** 五步全做完才發現第二步錯了，已經回不去。每個有副作用的步驟之前，都該想一下「這能退回嗎」。

**計畫不 review 就直接跑。** 有破壞性的操作沒有空跑、沒有確認，一錯就在正式環境出事。風險高的一定要有計畫加確認。

**重新規劃過度。** 每個小阻礙都重新規劃一次，結果永遠在規劃、從來不執行。要設一個重新規劃的門檻。

**計畫跟記憶不接。** 同樣的遷移每次都重新想一遍，過去的計畫沒有被重用。計畫範本該存進記憶。
